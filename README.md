#면접과제
면접 과제를 위한 레포지토리 이며 면접이 끝난 후에 자동 삭제됩니다. 
현재 개발 된 필터는 아래와 같습니다. 
- Grayscale
- Blur (sigma 0.8)
- Flip Horizontal (좌우 변경)
- Flip Vertical (상하 변경)
 
## 1. 🗂️ 프로젝트 Git
현재 브랜치는 **main**가 기본이며 이 브랜치에서 클론 받아주시면 감사드리겠습니다. 
Push 또는 Commit 하실 때 아래 구조와 사용설명에 따라주시면 감사드리겠습니다. 

### 1.1 브랜치를 추가합니다. 

*기능 추가* 시 아래와 같이 입력합니다. 
```
features/원하는 이름 
```
*버그로 인한* 브랜치 추가 시 아래와 같이 입력합니다. 
```
bug/버그가 발생한 기능브랜치 이름 사용 
```
**기타 사항** 
dev: 개발 후 머징될 브랜치입니다. 
release: 릴리즈 버전 배포 시 사용될 브랜치입니다. 
beta: 베타 테스트 시 사용될 브랜치입니다. 
 
**dev**는 머징만을 위해 사용합니다. 
**beta**는 머징 후 테스트 할 때 태그로 버전을 붙여 빌드합니다. 
**release**는 실제 라이브러리 배포시 태그로 버전을 붙여 빌드 후 각 플랫폼에 배포합니다. 
 
### 1.2 Commit를 합니다. 
*기능추가* 
``` 
feat: 원하는 문구 입력 
``` 
*기능수정* 
``` 
chore: 원하는 문구 입력 
``` 
*버그수정* 
``` 
fix: 원하는 문구입력 
``` 
 
### 1.3 더욱 최적화된 사용법을 추가 시 연락주십시오. 언제든지 오픈되어 있습니다. 
현재 사용방법보다 더욱 최적화된 사용방법이 있다면 연락주십시오.🙇‍♀️  
 
## 2. 💻 프로젝트 언어 
 
- 언어는 C++ 17 STD 
- 빌드는 VS에서 진행합니다. 
 
### 2.1 사용 IDE 
- Visual Studio 2026 ARM 64 (Visual Studio 2022 v143 x86_64 플랫폼 집합 포함) 



## 3. 💾 디버깅 방법 (윈도우 기준) 
- 프로젝트 폴더에서 **ImageProcessor.sln**을 Visual Studio에서 엽니다.  
- 프로젝트는 Visual Studio 2022 x86_64에 맞춰져 있으므로 다른 버전 사용 시 버전에 맞는 플랫폼 집합을 설치 후 사용해야 합니다. 
- 솔루션 탐색기에서 속성 > 디버깅 > 미리 디버깅을 위한 인수를 작성 합니다. 
- 빌드된 파일.exe --input 이미지 파일.bmp --output 저장될 이미지 경로 --filter 필터이름 로 사용
- 빌드된 파일.exe --input 이미지 파일.bmp --output 저장될 이미지 경로 --pipeline "필터이름, 필터이름..." 로 사용
